Arreglo Privacy Policy

Data Collection

We collect the following anonymous data with user consent:

  • Song metadata (genre, tempo, length)
  • Pattern types and names (anonymized)
  • Arrangement structure
  • API performance metrics
  • Error logs (if any)

We never collect:

  • Personal information
  • API keys
  • Actual song titles or content
  • User identifiers

Data Usage

Collected data is used to:

  • Improve arrangement algorithms
  • Identify common patterns
  • Fix bugs and errors
  • Enhance user experience
