# Arreglo Documentation

## Project Overview

Arreglo is an AI-powered music arrangement visualization tool that helps music producers plan and visualize song structures. Currently implemented as a Figma plugin with advanced prompt engineering and genre-specific intelligence for professional dance music arrangement generation.

**Version 2.0** introduces revolutionary multi-stage AI architecture, pattern relationship intelligence, and genre-specialist knowledge for house, techno, and trance music.

